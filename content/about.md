I'm George Mathieson, a software developer.

I construct web applications with a focus on the human element. I prioritise user interface design, ensuring that complex code feels simple and delightful to use.

This site is my journal — experiments, thoughts, and code. I write about the technical side of building software and about delivery: how teams ship, how we measure whether any of it mattered, and what I'm learning along the way.

The site itself is built with [Hugo](https://gohugo.io/), styled with hand-written SCSS, and hosted on GitHub Pages. No trackers, no ads — just words.
